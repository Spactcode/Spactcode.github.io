#### #집합 자료형

집합(set)은 파이썬 2.3부터 지원하기 시작한 자료형으로, 집합에 관련된 것을 쉽게 처리하기 위해 만든 자료형이다.

집합 자료형은 아래와 같이 set 키워드를 사용해 만들 수 있다.

아래 예시를 보면 set()의 괄호 안에 리스트를 입력하여 만들거나 문자열을 입력하여 만들 수도 있다. 또한 비어 있는 집합 자료형은 괄호 안을 비워주면 된다.

> &gt;&gt;&gt; s1 = set (\[1,2,3\])  
> &gt;&gt;&gt; s1  
> {1, 2, 3}
{: data-ke-style="style3"}

> &gt;&gt;&gt; s2 = set("Hello")  
> &gt;&gt;&gt; s2  
> {'o', 'H', 'e', 'l'}
{: data-ke-style="style3"}

> &gt;&gt;&gt; s3 = set()
{: data-ke-style="style3"}

#### #집합 자료형의 특징

위에서 본 예시들 중 이상한 점이 하나 있을 것이다. set("Hello")의 결과가 좀 이상하게 보인다. 분명 Hello 문자열로 set 자료형을 만ㄷ르었는데 생성된 자료형에는 l 문자가 하나 빠져 있고 순서도 무작위로 되어있다. 그 이유는 set에 2가지 큰 특징이 있기 때문이다.

> 1\. 중복을 허용하지 않는다.  
> 2\. 순서가 없다(unordered).
{: data-ke-style="style3"}

리스트나 튜플은 순서가 있다. 그렇기 때문에 인덱싱을 통해 자료형의 값을 얻을 수 있다. 하지만 set 자료형은 순서가 없기 때문에 인덱싱으로 값을 더을 수 없다. 이는 마치 딕셔너리와 비슷하다. 딕셔너리 역시 순서가 없는 자료형이기 때문에 인덱싱을 지원하지 않는다.

만약 set 자료형에 저장된 값을 인덱싱으로 접근하려면 아래와 같이 리스트나 튜플로 변환한 후 해야한다.

> &gt;&gt;&gt; s1 = set(\[1,2,3\]  
> &gt;&gt;&gt; l1 = list(s1)  
> &gt;&gt;&gt; l1  
> \[1, 2, 3\]  
> &gt;&gt;&gt; l1\[0\]  
> 1  
> &gt;&gt;&gt; t1 = tuple(s1)  
> &gt;&gt;&gt; t1  
> (1, 2, 3)  
> &gt;&gt;&gt; t1\[0\]  
> 1
{: data-ke-style="style3"}

#### #교집합, 합집합, 차집합 구하기

우리는 학창시절 확률과 통계를 배울때 집합(교집합, 합집합, 차집합)을 배운 기억이 있을 것이다. 파이썬에서도 set 자료형을 정말 유용하게 사용하는 경우는 교집합, 합집합, 차집합을 구할 때이다.

아래와 같이 2개의 set 자료형을 만들어 보자. s1은 1부터 6까지의 값을. s2는 4부터 9까지의 값을 가지게 되었다.

> &gt;&gt;&gt; s1 = set(\[1, 2, 3, 4, 5, 6\])  
> &gt;&gt;&gt; s2 = set(\[4, 5, 6, 7, 8, 9\])
{: data-ke-style="style3"}

#### STEP1. 교집합

s1과 s2의 교집합을 구해보면 아래와 같이 '&amp;' 기호를 통해 교집합을 간단히 구할 수 있는 것을 확인할 수 있다. intersection 함수를 사용해도 동일한 결과를 돌려준다.

> &gt;&gt;&gt; s1 &amp; s2  
> {4, 5, 6}
{: data-ke-style="style3"}

> &gt;&gt;&gt; s1.intersection (s2)  
> {4, 5, 6}
{: data-ke-style="style3"}

#### STEP2. 합집합

합집합은 아래와 같이 구할 수 있다. 이때 4, 5, 6처럼 중복된 값은 한 개씩만 표현된다. 합집합을 구할 때에는 '&#124;'를 사용하거나 union 함수를 사용하면 된다.

> &gt;&gt;&gt; s1&#124;s2  
> {1, 2, 3, 4, 5, 6, 7, 8, 9}
{: data-ke-style="style3"}

> &gt;&gt;&gt; s1.union(s2)  
> {1, 2, 3, 4, 5, 6, 7, 8, 9}
{: data-ke-style="style3"}

#### STEP3. 차집합

차집합은 빼기(-)기호를 사용하거나 differnce 함수를 사용하면 구할 수 있다.

> &gt;&gt;&gt; s1 - s2  
> {1, 2, 3}  
> &gt;&gt;&gt; s2 - s1  
> {8, 9, 7}
{: data-ke-style="style3"}

> &gt;&gt;&gt; s1.difference(s2)  
> {1, 2, 3}  
> &gt;&gt;&gt; s2.difference(s1)  
> {8, 9, 7}
{: data-ke-style="style3"}

#### #집합 자료형 관련 함수

#### STEP1. 값 1개 추가하기(add)

이미 만들어진 set 자료형에 값을 추가할 수 있다. 1개의 값만 추가(add)할 경우 아래와 같이 한다.

> &gt;&gt;&gt; s1 = set(\[1, 2, 3\])  
> &gt;&gt;&gt; s1.add(4)  
> &gt;&gt;&gt; s1  
> {1, 2, 3, 4}
{: data-ke-style="style3"}

#### STEP2. 값 여러 개 추가하기(update)

여러 개의 값을 한꺼번에 추가(update)할 때는 아래와 같이 하면 된다.

> &gt;&gt;&gt; s1 =set(\[1, 2, 3\])  
> &gt;&gt;&gt; s1.update(\[4, 5, 6\])  
> &gt;&gt;&gt; s1  
> {1, 2, 3, 4, 5, 6}
{: data-ke-style="style3"}

#### STEP3. 특정 값 제거하기(remove)

특정 값을 제거하고 싶은 경우 아래와 같이 하면 된다.

> &gt;&gt;&gt; s1 =set(\[1, 2, 3\])  
> &gt;&gt;&gt; s1.remove(2)  
> &gt;&gt;&gt; s1  
> {1, 3}
{: data-ke-style="style3"}

#### #불 자료형

불(bool)자료형이란 참(true)과 거짓(False)을 나타내는 자료형이다. 불 자료형은 아래와 같은 값만을 가질 수 있다.(이때 첫 문자는 항상 대문자로 사용해야한다. -&gt; 예약어이기 때문!)

> True : 참  
> False : 거짓
{: data-ke-style="style3"}

아래와 같이 변수 a에는 True, 변수 b에는 False를 지정해 보자.

> &gt;&gt;&gt; a = True  
> &gt;&gt;&gt; b = False
{: data-ke-style="style3"}

따옴표로 감싸지 않은 문자열을 변수에 지정해서 오류가 발생할 것이라고 생각이 들것이다. 하지만 잘 실행된다. type 함수를 변수 a와 b에 사용하면 두 변수의 자료형이 bool로 지정된 것을 확인할 수 있다.

> &gt;&gt;&gt; type(a)  
> &lt;class 'bool'&gt;  
> &gt;&gt;&gt; type(b)  
> &lt;class 'bool'&gt;
{: data-ke-style="style3"}

불 자료형은 조건문의 반환 값으로도 사용된다.

> &gt;&gt;&gt; 1 == 1  
> True
{: data-ke-style="style3"}

1 == 1 은 1과 1이 같은가를 묻는 조건문이다. 당연히 같기 때문에 결과로  True를 돌려준것이다.

만약 아래와 같이 2는 1보다 작은지 물어보는 조건문은 당연히 틀리기 때문에 False를 돌려준다.

> &gt;&gt;&gt; 2 &lt; 1  
> False
{: data-ke-style="style3"}

#### #자료형의 참과 거짓

자료형에는 참과 거짓이 있다. 아래 표를 살펴보자.

아래 표는 자료형의 참과 거짓을 구분하는 기준을 나타내준다. 문자열, 리스트, 튜플, 딕셔너리 드으이 값이 비어 있으면("", \[ \], ( ), {}) 거짓이 된다. 반대로 비어있지 않으면 참이 된다. 아래 표를 보면 None이 보일 것이다. None은 거짓을 뜻한다 정도만 정리하고 넘어가겠다.

예시를 하나 들어보겠다. 아래 예시를 보면 a가 참일 경우 a.pop()을 계속 실행하라는 의미이다.만약 a가 참이 아닐 경우 조건이 거짓이 되므로 중지된다.

> &gt;&gt;&gt; a = \[1, 2, 3, 4\]  
> &gt;&gt;&gt; while a:  
>               a.pop
{: data-ke-style="style3"}

> &gt;&gt;&gt; if \[1, 2, 3\]:  
>          print("참")  
>         else:  
>           print("거짓")
{: data-ke-style="style3"}

#### #불 연산

자료형에 참과 거짓이 있음을 알아보았다. bool 내장 함수를 사용하면 자료형의 참과 거짓을 식별할 수 있지 않을까?

아래 예시를 봐보자.

> &gt;&gt;&gt; bool('python')  
> True
{: data-ke-style="style3"}

'python'문자열은 빈 문자열이 아니므로 bool 연산의 결과로 불 자료형인 True를 돌려준다.

> &gt;&gt;&gt; bool('')  
> False
{: data-ke-style="style3"}

하지만 반면 ''문자열은 빈 문자열이므로 bool 연산의 결과로 불 자료형인 False를 돌려준다.

\*추가 예시

> &gt;&gt;&gt; bool(\[1,2,3\])  
> True  
>   
> &gt;&gt;&gt; bool(\[\])  
> False  
>   
> &gt;&gt;&gt; bool(0)  
> False  
>   
> &gt;&gt;&gt; bool(3)  
> True
{: data-ke-style="style3"}

#### #자료형의 값을 저장하는 공간, 변수

우리가 지금까지 자연스럽게 써왔던 변수에 대해 알아볼려고 한다. 

아래 예시에 있는 a,b,c를 변수라고 한다. 

> &gt;&gt;&gt; a = 1  
> &gt;&gt;&gt; b = "python"  
> &gt;&gt;&gt; c = \[1,2,3\]
{: data-ke-style="style3"}

변수를 만들 때는 위 예시처럼 =(assignment) 기호를 사용한다.

> 변수 이름 = 변수에 저장할 값
{: data-ke-style="style3"}

#### #변수

이제 변수에 대해 더 자세하게 알아보자.

변수는 객체를 가리키는 것이라고 말할 수 있다. 여기서 객체란 우리가 보았던 자료형과 같은 것을 의미하는 말이다. 

아래 코드처럼 a = \[3, 6, 9\]라고 하면 \[3, 6, 9\] 값을 가지는 리스트 자료형(객체)이 자동으로 메모리에 생성되고 변수인 a는 \[3, 6, 9\]가 저장된 메모리의 주소를 가리키데 된다.(메모리란 컴퓨터가 프로그램에서 사용하는 데이터를 기억하는 공간을 말한다.) 

> &gt;&gt;&gt; a = \[3, 6, 9\]
{: data-ke-style="style3"}

a 변수가 가리키는 메모리의 주소는 아래와 같이 확인할 수 있다.

> &gt;&gt;&gt; a = \[3, 6, 9\]  
> &gt;&gt;&gt; id(a)  
> 2010170176064
{: data-ke-style="style3"}

id 함수는 변수가 가리키고 있는 객체의 주소 값을 돌려주는 파이썬 내장 함수이다. 즉 여기에서 만든 변수 a가 가리키는 \[1, 2, 3\] 리스트의 주소 값은 2010170176064 임을 알 수 있다.

#### #리스트를 복사할 경우

리스트 자료형에서 가장 혼동하기 쉬운 '복사'에 대해 알아보려고 한다. 아래 예시를 통해 알아보자.

> &gt;&gt;&gt; a = \[3, 6, 9\]  
> &gt;&gt;&gt; b = a
{: data-ke-style="style3"}

b변수에 a 변수를 대입하면 어떻게 될까?

결론적으로 a와 b는 완전히 동일하다. 다만 \[3, 6, 9\] 리스트는 참조하는 변수가 a변수 1개에서 b변수가 추가되어 2개로 늘어났다는 차이만 있을 뿐이다. id 함수를 사용하면 아래와 같이 확인할 수 있다.

> &gt;&gt;&gt; id(a)  
> 2010170176064  
> &gt;&gt;&gt; id(b)  
> 2010170176064
{: data-ke-style="style3"}

id(a)의 값이 id(b)의 값과 동일함을 확인할 수 있다. 즉 a가 가리키는 대상과 b가 가리키는 대상이 동일하다는 것을 알 수 있다. 동일한 객체를 가리키고 있는지에 대해 판단하는 파이썬 명령어인 is를 실행해도 역시 참(True)을 돌려준다.

> &gt;&gt;&gt; a is b  
> True
{: data-ke-style="style3"}

> &gt;&gt;&gt; a\[1\] = 4  
> &gt;&gt;&gt; a  
> \[3, 4, 9\]  
> &gt;&gt;&gt; b  
> \[3, 4, 9\]
{: data-ke-style="style3"}

a 리스트의 두 번째 요소를 값 4로 바꾸었더니 a만 바뀌는 것이 아니라 b도 똑같이 바뀐것을 확인 할 수 있다. 그 이유는 a, b 모두 동일한 리스트를 가리키고 있기 때문이다. 그렇다면 b 변수를 생성할 때 a 변수의 값을 가져오면서 a와는 다른 주소를 가리키도록 만들 수는 없을까? 아래 2가지 방법을 소개하겠다.

#### STEP1. \[:\]

첫 번째 방법은 아래와 같이 리스트 전체를 가리키는 \[:\]을 사용해서 복사하는 것이다.

아래와 같이 a 리스트 값이 바뀌더라도 b 리스트에는 영향을 미치지 않는 것을 알 수 있다.

> &gt;&gt;&gt; a = \[3, 6, 9\]  
> &gt;&gt;&gt; b = a\[:\]  
> &gt;&gt;&gt; a\[1\] = 4  
> &gt;&gt;&gt; a  
> \[3, 4, 9\]  
> &gt;&gt;&gt; b  
> \[3, 6, 9\]
{: data-ke-style="style3"}

#### STEP2. copy 모듈

두 번째는 copy 모듈을 사용하는 것이다. 아래 예시를 보면 from copy improt copy라는 부분이 보일 것이다. 이것은 copy 함수를 사용하기 위해 사용한 것이다. 여기서 b = copy(a)는 b = a\[:\]과 동일하다.

> &gt;&gt;&gt; from copy improt copy  
> &gt;&gt;&gt; a = \[3, 6, 9\]  
> &gt;&gt;&gt; b = copy(a)
{: data-ke-style="style3"}

두 변수가 같은 값을 가지면서 다른 객체를 제대로 생성했는지 확인해 보면 b is a가 False를 돌려주므로 b와 a가 가리키는 객체는 서로 다르다는 것을 알 수 있다.

> &gt;&gt;&gt; a  
> \[3, 6, 9\]  
> &gt;&gt;&gt; b  
> \[3, 6, 9\]  
> &gt;&gt;&gt; b is a  
> False
{: data-ke-style="style3"}

#### #변수를 만드는 방법들

아래와 같이 튜플로 a,b에 값을 대입할 수 있다. 또한 튜플은 괄호를 생략하도 된다.

> &gt;&gt;&gt; a, b = ('python', 'life')  
>   
> &gt;&gt;&gt; (a, b) = 'python', 'life'
{: data-ke-style="style3"}

아래처럼 리스트로 변수도 만들 수 있다.

> &gt;&gt;&gt; \[a, b\] = \['python', 'life'\]
{: data-ke-style="style3"}

또한 여러 개의 변수에 같은 값을 대입할 수도 있다. 이를 사용하므로써 파이썬에서는 두 변수의 값을 아주 간단히 바꿀 수 있다.

> &gt;&gt;&gt; a = b = 'python'
{: data-ke-style="style3"}

> &gt;&gt;&gt; a = 3  
> &gt;&gt;&gt; b = 5  
> &gt;&gt;&gt; a, b = b, a  
> &gt;&gt;&gt; a  
> 5  
> &gt;&gt;&gt; b  
> 3
