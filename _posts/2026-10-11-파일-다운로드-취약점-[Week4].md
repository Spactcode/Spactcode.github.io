#### <strong><span style="color: #000000;"># 파일 다운로드 취약점</span></strong>

#### <strong><span style="color: #000000;">1. 공격 원리</span></strong>

정상적인 파일 다운로드 기능은 사용자가 요청한 파일을 애플리케이션의 지정된 경로에서 불러와 다운로드되는 방식으로 진행된다. 공격자가 기능에 대입하면 파일명을 조작하여 애플리케이션의 지정된 경로에서 벗어나 다른 경로에 존재하는 임의의 파일을 다운로드하게 한다. 이렇게 비정상적으로 파일을 다운로드하는 행위를 <strong>파일 다운로드 취약점</strong>이라고 한다.

> 파일 다운로드 취약점은 파일명을 조작하여 애플리케이션의 지정된 경로에서 벗어난 경로에 존재하는 임의의 파일을 다운로드하므로 이 공격의 핵심은 '경로 조작'이다. 지정된 경로를 벗어나게 하기 위해서는 파일 명을 조작하는데, 이때 경로 이동 문자를 사용해야 한다.
{: data-ke-style="style3"}

#### <strong><span style="color: #000000;">1. 공격 목표</span></strong>

파일 다운로드 취약점은 지정된 경로에서 벗어난 경로에 존재하는 임의의 파일을 다운로드하는 방식이다. 이 임의의 파일이 공격자가 다운로드를 유도하 파일이며, 그 내용은 공격자의 목표에 따라 달라진다.

> 리눅스/유닉스 서버 환경일 경우 → /etc/passwd 파일 다운로드를 통해 사용자 계정 및 홈 디렉터리 경로 확인 가능  
> 웹 애플리케이션 서버 구동 권한이 서버 내 root 계정이라면 → /etc/shadow 파일 다운로드를 통해 패스워드 해시 값을 알아낼 수 있고 , 패스워드 크랙 도구를 통해 크랙 시도를 해볼 수 있음.
{: data-ke-style="style3"}

#### <strong><span style="color: #000000;"># 운영체제별 파일 시스템의 구조적 차이</span></strong>

파일 다운로드 취약점을 활용하기 위해서는 운영체제별 파일 시스템에 어떤 구조적 차이가 있는지 알아야 한다.

#### <strong><span style="color: #000000;">윈도우의 파일 시스템</span></strong>

윈도우 파일 시스템은 저장 장치가 별도의 파티션으로 구분된다.

> Ex) C 드라이브, D 드라이브, E 드라이브 등
{: data-ke-style="style3"}

또한 단순히 경로 이동 문자로는 파티션이 변경되지 않는다. 경로 이동 문자를 아무리 입력해도 파티션 최상위에서 벗어나지 않는 것을 확인할 수 있다. 만약 파티션을 이동하고 싶다면 해당 드라이브 명칭을 입력해야 한다.

```bash
C:\Users\SpacCode> cd ../../../../../../
C:\>

C:\Users\SpacCode>d:
D:\>
```

따라서 파일 다운로드 취약점 공격 시 윈도우 환경에서는 지정된 경로의 파티션 안에서만 이동할 수 있다. 물론 윈도우 운영 체제를 사용해도 파티션이 변경되는 경우도 있다. 사용자에게 절대 경로를 받는 경우이다.

> Ex) download.jsp?path=c:\\tomcat\\webapps\\ROOT\\upload&amp;file name=test.png 이렇게 path 파라미터에 절대 경로 전체를 입력받을 경우 path 파라미터의 파티션을 변조하면 다른 파티션으로 접근이 가능하다.
{: data-ke-style="style3"}

#### <strong><span style="color: #000000;">리눅스/유닉스의 파일 시스템</span></strong>

리눅스와 유닉스 파일 시스템은 단일 트리 구조로, 트리의 시작점은 / 디렉터리다. 이를 <strong>루트 디렉터리</strong>라고 부른다.

> 윈도우와 달리 리눅스/유닉스는 하나의 디렉터리 안에 모든 디렉터리, 파일이 존재하는 것
{: data-ke-style="style3"}

단일 트리 구조는 파일 다운로드 취약점 공격 관점에서 매우 좋은 구조로, 상위 이동을 통해 어디든 갈 수 있다. (권한의 제약이 있을 수 있음)  
리눅스/유닉스 서버는 공통으로 존재하는 설정 파일인 /etc/passwd, /etc/shadow, /etc/hosts를 다운로드 받을 수 있다.

#### <strong><span style="color: #000000;">실무에서는?</span></strong>

실무에서 다른 취약점들을 찾기 위해 파일 다운로드 취약점을 많이 사용한다. 웹셸 업로드를 하기 위해서는 많은 정보가 필요한데, 그 정보 제공자 역할을 하는 것이 파일 다운로드 취약점이기 때문이다.
