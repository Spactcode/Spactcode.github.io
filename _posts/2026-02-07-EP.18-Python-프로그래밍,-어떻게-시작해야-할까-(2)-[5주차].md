#### #간단한 메모장 만들기

무언가를 꼭 적어놓아야 하는 것이 있을 때 자주 사용하는 메모장을 만들어 보자. 메모장의 기능은 어떤 것이 가능해야 할까?

> 메모를 추가 가능해야한다.  
> 메모를 조회할 수 있어야 한다.  
> 메모 내용을 입력 가능해야 한다.  
> 출력하는 값은 memo.txt로 하자.
{: data-ke-style="style3"}

그렇다면 가장 먼저 해야 할 일은 메모를 추가하는 것이다. 아래 명령을 실행했을 때 메모를 추가할 수 있도록 만들어 보자.

> Python memo.py -a "Life is too short"
{: data-ke-style="style3"}

여기서 memo.py는 파이썬 프로그램 이름이고, -a는 이 프로그램의 실행 옵션, "Life is too short"는 추가할 메모 내용이 된다.

#### STEP.1 옵션과 메모 출력 코드 만들기

> import sys  
>   
> option = sys.argv\[1\]  
> memo = sys.argv\[2\]  
>   
> print(option)  
> print(memo)
{: data-ke-style="style3"}

sys.argv는 프로그램을 실행할 때 입력된 값을 읽어 들일 수 잇는 파이썬 라이브러리이다. sys.argv\[0\]는 입력받은 값 중에서 파이썬 프로그램 이름인 memo.py이므로 만들려는 기능에는 필요 없는 값이다. 또한 순서대로 sys.argv\[1\]은 프로그램 실행 옵션 값이 되고 sys.argv\[2\]는 메모 내용이 된다.

#### STEP.2 출력 확인하기

> \-a  
> Life is too short
{: data-ke-style="style3"}

입력으로 전달한 옵션과 메모 내용이 그대로 출력되는 것을 확인할 수 있다.

#### STEP.3 입력 받은 메모 파일에 쓰게 만들기

이제 입력으로 받은 메모를 파일에 쓰도록 코드를 구성해보자.

> import sys  
>   
> option = sys.argv\[1\]  
>   
> if option == '-a':  
>     memo = sys.argv\[2\]  
>     f = open('memo.txt', 'a')  
>     f.write(memo)  
>     f.write('\\n')  
>     f.close()
{: data-ke-style="style3"}

옵션이 -a인 경우에만 memo 값을 읽어 memo.txt 파일에 그 값을 쓰도록 코드를 작성했다. 여기에서 메모는 항상 새로운 내용이 작성되는 것이 아닌 한 줄씩 추가되어야 하므로 파일 열기 모드를 a로했다. 그리고 메모를 추가할 때마다 다음 줄에 저장되도록 줄바꿈 문자(\\n)도 추가로 파일에 쓰게 했다.

#### STEP.4 명령 수행해보기

아래 명령을 수행해보자.

> python memo.py -a "Life is too short"
{: data-ke-style="style3"}

이후 파일에 정상적으로 메모가 기입되었는지 아래와 같이 확인해 볼 수 있다.

> Life is too short
{: data-ke-style="style3"}

추가한 메모가 정상적으로 저장된 것을 확인할 수 있다.

#### STEP.5 메모 출력 만들기

이제 작성한 메모를 출력하는 부분을 만들 것이다. 메모 출력은 -v 옵션을 사용한다.

> python memo.py -v
{: data-ke-style="style3"}

이제 메모 출력을 위해 아래와 같이 코드를 수정하였다.

> import sys  
>   
> option = sys.argv\[1\]  
>   
> if option == '-a':  
>     memo = sys.argv\[2\]  
>     f = open('memo.txt', 'a')  
>     f.write(memo)  
>     f.write('\\n')  
>     f.close()  
> elif option == '-v':  
>     f = open('memo.txt')  
>     memo = f.read()  
>     f.close()  
>     print(memo)
{: data-ke-style="style3"}

옵션으로 -v가 들어온 경우 memo.txt 파일을 읽어서 출력한다.

#### STEP.6 마무리

코드를 수정한 후 아래와 같이 명령을 수행해보면 입련한 메모가 그대로 출력되는 것을 확인할 수 있다.

> python memo.py -v
{: data-ke-style="style3"}

> Life is too shrot
{: data-ke-style="style3"}

#### #탭을 4개의 공백으로 바꾸기

이번에는 문서 파일을 읽어서 그 문서 파일 안에 있는 탭(tab)을 공백(space) 4개로 바꾸어 주는 스크립트를 작성해보자. 그렇다면 어떻게 만들면 좋을까? 한번 생각해보자.

> 문서 파일을 읽고, 문자열을 변경할 수 있는 기능이 필요하겠다.  
> 탭을 포함한 문서 파일을 입력 받아야겠다.  
> 탭이 공백으로 수정된 문서파일을 출력 값으로 가져야겠다.
{: data-ke-style="style3"}

아래와 같은 형식으로 프로그램이 수행되도록 만들면 될 것 같다.

> python table.py src dst
{: data-ke-style="style3"}

여기서 table.py는 작성해야 할 파이썬 프로그램 이름이고, src는 탭을 포함하고 있는 원본 파일 이름이다. dst는 파일 안의 탭을 공백4개로 변환한 결과를 저장할 파일 이름이다.

예를 한번 생각해 보자. a.txt 파일이 있고 이 파일에 있는 탭을 4개의 공백으로 바꾸어 b.txt 파일에 저장하고 싶다면 아래와 같이 수행하면 될 것이다.

> python table.py a.txt b.txt
{: data-ke-style="style3"}

#### STEP.1 table.py 파일 작성하기

먼저 table.py 파일을 작성해 보자.

> import sys  
>   
> src = sys.argv\[1\]  
> dst = sys.argv\[2\]  
>   
> print(src)  
> print(dst)
{: data-ke-style="style3"}

sys.argv를 사용하여 입력값을 확인하도록 만든 코드이다.

#### STEP.2 출력 확인하기

아래와 같이 수행했을 때 입력값이 정상적으로 출력되는지 확인해 보자.

> python table.py a.txt b.txt
{: data-ke-style="style3"}

입력으로 전달한 a.txt와 b.txt가 정상적으로 출력되는 것을 확인할 수 있다.

> a.txt  
> b.txt
{: data-ke-style="style3"}

#### STEP.3 탭 문자로 분리하기

테스트를 위한 탭을 포함하는 파일인 a.txt를 아래와 같이 작성한다. 각 단어는 탭(\\t) 문자로 분리되도록 입력해야 한다.

> Life   is   too   short  
> You   need   python
{: data-ke-style="style3"}

#### STEP.4 공백 변환 만들기

이제 탭 문자를 포함한 a.txt 파일을 읽어서 탭을 공백 4개로 변환할 수 있도록 코드를 변경해 보자.

아래 코드는 src에 해당되는 입력 파일을 읽어서 그 내용을 tab\_content라는 변수에 저장한 후 문자열의 replace 함수를 사용하여 탭(\\t)을 4개의 공백으로 변경하는 코드이다.

> import sys  
>   
> src = sys.argv\[1\]  
> dst = sys.argv\[2\]  
>   
> f = open(src)  
> tab\_content = f.read()  
> f.close()  
>   
> space\_content = tab\_content.replace("\\t", " "\*4)  
> print(space\_content)
{: data-ke-style="style3"}

#### STEP.5 확인하기

table.py를 아래와 같은 명령을 수행해보자.

> python table.py a.txt b.txt
{: data-ke-style="style3"}

아마도 탭 문자가 공백 4개로 변경되어 출력될 것이다. 하지만 탭과 공백의 차이점을 눈으로 알 수 없다. 따라서 탭이 정상적으로 공백으로 변경되었는지 확인하기란 어렵다.

> Life   is   too   short  
> You   need   python
{: data-ke-style="style3"}

#### STEP.6 b.txt 파일에 저장하기

이제 변경된 내용을 b.txt 파일에 저장할 수 있도록 아래와 같이 코드를 수정해 보자.

탭이 공백으로 변경된 space\_content를 출력 파일인 dst에 쓰도록 코드를 수정하였다.

> import sys  
>   
> src = sys.argv\[1\]  
> dst = sys.argv\[2\]  
>   
> f = open(src)  
> tab\_content = f.read()  
> f.close()  
>   
> space\_content = tab\_content.replace("\\t", " "\*4)  
> f = open(dst, 'w')  
> f.write(space\_content)  
> f.close()
{: data-ke-style="style3"}

#### STEP.7 마무리

프로그램을 실행하기 위해 아래와 같은 명령을 수행한다.

> python table.py a.txt b.txt
{: data-ke-style="style3"}

명령을 수행하면 b.txt 파일이 디렉터리에 생성된다. b.txt 파일을 열어서 탭이 4개의 공백 문자로 변경되었는지 확인해 볼 수 있다.

#### #하위 디렉터리 검색하기

특정 디렉터리부터 시작해서 그 하위 모든 파일 중 파이썬 파일(\*.py)만 출력해주는 프로그램을 만들어 보자.

#### STEP.1 파일 작성하기

아래와 같이 dir\_search.py 파일을 장성해 보자.

> def search(dirname):  
>       print(dirname)  
>   
> search("C:/")
{: data-ke-style="style3"}

search 함수를 만들고 시작 데럭터리를 입력받도록 작성하였다.

#### STEP.2 파일 검색 코드 작성하기

이제 이 디렉터리에 있는 파일을 검색할 수 있도록 코드를 변경해 보자.

> import os  
>   
> def search(dirname):  
>       filenames = os.listdir(dirname)  
>       for filename in filenames:  
>             full\_filename = os.path.join(dirname, filename)  
>             print(full\_filename)  
>   
> search("C:/")
{: data-ke-style="style3"}

os.listdir를 사용하면 해당 디렉터리에 있는 파일들의 리스트를 구할 수 있다. 여기서 구하는 파일 리스트는 파일 이름만 포함되어 있으므로 경로를 포함한 파일 이름을 구하기 위해서는 입력으로 받은 dirname을 앞에 덧붙여 주어야 한다. os 모듈에는 디렉터리와 파일 이름을 이어 주는 os.path.join 함수가 있으므로 이 함수를 사용하면 디렉터리를 포함한 전체 경로를 쉽게 구할 수 있다.

코드를 실행시키면 C:/ 디렉터리에 있는 파일이 출력될 것이다.

#### STEP.3 특정 확장자 파일만 출력하기

이제 C:/ 디렉터리에 있는 파일들 중 확장자가 .py인 파일만을 출력하도록 코들르 변경해 보자.

> import os  
>   
> def search(dirname):  
>       filenames = os.listdir(dirname)  
>       for filename in filenames:  
>            full\_filename = os.path.join(dirname, filename)  
>            ext = os.path.splitext(full\_filename)\[-1\]  
>            if ext == '.py':  
>                 print(full\_filename)  
>   
> search("C:/")
{: data-ke-style="style3"}

파일 이름에서 확장자만 추출하기 위해 os 모듈의 os.path.splitext 함수를 사용하였다. os.path.splitext는 파일 이름을 확장자를 기준으로 두 부분으로 나누어 준다. 따라서 os.path.splitext(full\_filename)\[-1\]은 해당 파일의 황장자 이름이 된다. 작성한 코드는 황장자 이름이 .py인 경우만을 출력하도록 만들었다. C:/ 디렉터리에서 파이썬 파일이 없다면 아무것도 출력되지 않는다.

#### STEP.4 하위 디렉터리 검색 기능 추가하기

지금까지 만든 코드는 C:/ 디렉터리 바로 밑에 있는 파일 뿐이다. 하지만 그 하위 디렉터리(sub directory)를 포함한 모든 파이썬 파일을 검색할려면 어떻게 해야할까? 아래와 같이 코드를 수정해 보자.

> import os  
>   
> def search(dirname):  
>    try:  
>       filenames = os.listdir(dirname)  
>       for filename in filenames:  
>            full\_filename = os.path.join(dirname, filename)  
>            if os.path.isdir(full\_filenames):  
>                 search(full\_filename)  
>            else:  
>                  ext = os.path.splitext(full\_filename)\[-1\]  
>                  if ext == '.py':  
>                      print(full\_filename)  
>       except PermissionError:  
>             pass  
>   
> search("C:/")
{: data-ke-style="style3"}

try와 except PermissionErrorfh로 함수 전체를 감쌌다. 그 이유는 os.listdir를 수행할 때 권한이 없는 디렉터리에 접근하더라도 프로그램이 오류로 종료되지 않고 수행되도록 하기 위해서이다. full\_filename이 디렉터리인지 파일인지 구별하기 위하여 os.path.isdir 함수를 사용하였고 디렉터리일 경우 해당 경로를 입력받아 다시 search 함수를 호출하였다. 이렇게 해당 디렉터리의 파일이 디렉터리일 경우 다시 search 함수를 호출해 나가면(재귀 호출) 해당 디렉터리의 하위 파일을 다시 검색하기 시작하므로 결국 모든 파일들을 검색할 수 있게 된다.

#### STEP.5 더 간단하게 만들기

시작 디렉터리부터 시작하여 그 하위 모든 디렉터리를 차례대로 방문하게 해주는 함수가 있다. 바로 os.walk이다. 이 함수를 사용한다면 더 간단하게 코드를 작성할 수 있다.

> import os  
>   
> for (path, dir, files) in os.walk("C:/"):  
>      for filename in files:  
>            ext = os.path.splitext(filename)\[-1\]  
>            if ext == '.py':  
>                print("%s/%s" % (path, filename))
{: data-ke-style="style3"}
