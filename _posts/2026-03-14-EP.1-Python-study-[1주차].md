#### #덧셈 게임 만들기

이번에 해결할 문제는 아래와 같다.

> <strong>[문제]</strong>  
> <strong><span style="color: #ee2323;">{1~99 정수} + {1~99 정수} =</span></strong> 형태의 문제를 출력, 사용자의 입력을 정수 형태로 받아서 출력된 문제의 정답과 일치한다면 <strong><span style="color: #ee2323;">Correct</span></strong> 출력 후 다음 문제 출력, 일치하지 않는다면 <strong><span style="color: #ee2323;">Wrong</span></strong> 문자열 출력 후 실행 종료  
>   
> 문제는 10번 출력되며, 10번의 문제를 모두 맞힐 경우 <strong><span style="color: #ee2323;"> Good Job!</span></strong> 문자열 출력 후 실행 종료
{: data-ke-style="style3"}

> <strong>예시1</strong>  
> 1: 75 + 63 = 138  
> Correct  
> 2: 59 + 4 = 63  
> Correct  
> 3: 49 + 61 = 110  
> Correct  
> 4: 70 + 33 = 103  
> Correct  
> 5: 66 + 72 = 138  
> Correct  
> 6: 74 + 1 = 75  
> Correct  
> 7: 57 + 36 = 93  
> Correct  
> 8: 25 + 67 = 92  
> Correct  
> 9: 27 + 88 = 115  
> Correct  
> 10: 73 + 41 = 114  
> Correct  
> Good Job!
{: data-ke-style="style3"}

> <strong>예시2</strong>  
> 1: 36 + 3 = 39  
> Correct  
> 2: 83 + 30 = 113  
> Correct  
> 3: 42 + 46 = 111111  
> Wrong
{: data-ke-style="style3"}

그렇다면 어떻게 만들어야 할까? 위 조건들을 바탕으로 생각을 정리해 보면 아래와 같을 것이다.

> 1&#126;99 정수 형태의 문제가 출력돼야 한다.  
> 사용자가 값을 입력할 수 있어야 한다.   
> 맞혔을 때는 Correct가, 틀렸을 대는 Wrong 문자열이 출력되어야 한다.  
> 총 10번의 문제가 출력되어야 하며 문제를 모두 맞히면 Good Job! 문자열이 출력된 후 실행 종료, 그렇지 않으면 그대로 실행 종료가 되어야 한다.  
> 10번의 문제가 출력되어야 하니 반목문인 for문을 사용하자.  
> 정답을 맞혔을 때와 틀렸을 때, 모두 맞췄을 때의 경우가 있으니 if문을 사용하자.
{: data-ke-style="style3"}

그럼 이 생각을 바탕으로 한번 코드를 구성해 보자.

#### STEP.1 함수 만들기

먼저 1부터 99까지의 수 중 랜덤으로 두 수가 생성되어 덧셈 문제를 생성해 내야 한다. 이를 def를 활용하여 함수를 만들어보자.

```python
def answer(a, b, answer):
    return (a + b) == answer
```

먼저 함수 이름은 answer로 지정하여 a, b, answer로 매개변수를 추가해 주었다. 이를 활용해 a+b == answer 값을 반환하고자 하였다.(이때 변수 이름과 함수가 전달받은 값이 모두 answer이므로 헷갈린다면 변수 이름을 변경해도 좋다.)

#### STEP.2 1&#126;99의 랜덤 한 정수 출력하기

1&#126;99의 랜덤 한 정수를 출력하기 위해 random 모듈을 가져왔다. 이후 이전에 매개변수로 추가해 준 a, b 값이 1부터 99까지의 수 중 랜덤 한 정수가 지정되도록 하였다.

```python
import random

a = random.randrange(1, 99)
b = random.randrange(1, 99)
```

print(a)와 print(b)를 입력해 보면 랜덤 한 값이 잘 출력되는 것을 확인할 수 있다.

#### STEP.3 랜덤 한 10 문제 만들기

이제 1부터 99까지의 a, b 값을 입력받아 랜덤 한 문제를 출력하는 기능을 만들어 보자. 총 10문제를 만들어야 하기 때문에 10번 반복해야 하며, 사용자가 그 문제에 대한 답을 입력할 수도 있게 만들어야겠다. 이때 사용자의 입력값은 정수여야 하겠다.

```python
import random

def answer(a, b, answer):
    return (a + b) == answer

for i in range(1, 11):

    a = random.randrange(1, 99)
    b = random.randrange(1, 99)

    x = int(input(f"{a} + {b} = "))
```

먼저 랜덤 한 a값과 b값을 출력하기 위해 문자열 포맷팅을 활용하였다. 또한 사용자의 값을 입력받아야 하므로 input을 사용하였으며 int로 정수값으로 변환하였다. 이렇게 사용자에게 입력받은 값은 x변수에 저장되도록 만들었다.

#### STEP.4 Correct or Wrong

이제 사용자가 입력한 값이 정답일 경우 Correct, 오답일 경우 Wrong이 출력되도록 만들어보자.

이를 위해 if문을 사용하여 이전에 a+b == answer로 answer함수를 만들어 놨으므로 만약 a와 b를 더했을 때 사용자가 입력한 x값이 참이라면 Correct를 아니라면 Wrong이 출력되도록 하였다. 여기서 answer가 사용자가 입력한 값을 저장해 둔 x가 되는 것이다. 또한 총 10문제가 필요하므로 범위를 (1,11)로 지정하였다.

```python
import random

def answer(a, b, answer):
    return (a + b) == answer

for i in range(1, 11):

    a = random.randrange(1, 99)
    b = random.randrange(1, 99)

    x = int(input(f"{a} + {b} = "))

    if answer(a, b, x):
        print("Correct")
    else:
        print("Wrong")
```

#### STEP.5 마무리

이제 모든 문제를 모두 맞혔을 경우 Good Job!이라는 문자열이 출력되도록 만들어 보자.

먼저 문제를 맞혔을 경우 Correct라는 문자열이 나온다. 그렇다면 몇 문제를 맞혔는지 카운트를 해줄 수 있는 변수가 필요하다. 그리하여 y라는 카운트 변수를 만들어 초기값을 0으로 지정해 주었다. 이후 만약 정답을 맞혔을 경우 y값에 1씩 더해지도록 하여 만약 다 맞출 경우 10이 되도록 하였다. 또한 if문을 추가하여 만약 y가 10이라면 Good Job!이라는 문자열이 출력되도록 하였다.

```python
import random

def answer(a, b, answer):
    return (a + b) == answer

y = 0

for i in range(1, 11):

    a = random.randrange(1, 99)
    b = random.randrange(1, 99)

    x = int(input(f"{a} + {b} = "))

    if answer(a, b, x):
        y+=1
        print("Correct")
    else:
        print("Wrong")

    if y == 10:
        print("Good Job!")
```

이 코드를 실행해 보면 아래 이미지처럼 문제가 나오고 문제를 맞히면 Correct, 틀리면 Wrong, 모두 맞출 시 Good Job!이 출력되는 것을 확인할 수 있다.
