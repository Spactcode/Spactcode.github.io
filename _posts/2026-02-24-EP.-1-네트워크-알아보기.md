#### #네트워크 그리고 인터넷과 웹

네트워크란 무엇일까? 

우리는 종종 네트워크라는 말을 들을 때가 있다. 네트워크는 간단히 생각하면 무언가 서로 얽혀있고 연결되어있어 무언인가를 주고 받는 것이다. 인터넷, 웹, 와이파이를 떠올려도 조금은 상상이 갈 것이다. 그렇다면 네트워크에 대해 자세하게 알아보자.

#### 네트워크와 인터넷 톺아보기

네트워크라는 말을 처음 듣게 되면 인터넷인가? 하고 생각이 든다. 틀린 말은 아니지만 좀 더 정확하게 구분해 보자. 먼저 네트워크는 여러 컴퓨터를 연결한 통신망인다. 즉 컴퓨터를 2대를 연결해도 하나의 통신망이자 네트워크라고 할 수 있다. 그렇다면 집에서 우리가 컴퓨터와 공유기를 연결하고, 휴대폰과 TV등 서로 다른 장치를 연결한다. 이것 또한 네트워크인 것이다.

그렇다면 네트워크와 인터넷은 정확히 같은 말일까?

인터넷은 세상에 존재하는 무수히 많은 통신망 가운데 규모가 가장 큰 네트워크이다. 즉, 전 세계에 있는 컴퓨터를 모두 연결할 만큼 큰 네트워크가 인터넷인 것이다. 즉 인터넷은 네트워크와 네트워크를 연결한 더 넓은 의미를 갖고 있다. 우리는 이런 인터넷을 통해 다른 국가의 친구와 다른 지역의 가족들과 데이터를 쉽게 빠르게 주고 받는다.(실제로 해외에 있는 친구에게 카톡할 수 있지 않는가?) 또한 실제로 인터넷은 각 나라의 주요 도시를 해저 케이블로 연결하고 있다. 이렇게 주요 도시에 있는 작은 네트워크들이 서로 연결되어 큰 네트워크를 구성한다.

#### 웹과 웹 서비스

이번에는 웹에 대해 알아보자.

웹(web)이란 일반적으로 웹 서비스를 말한다. 웹 서비스는 웹 브라우저(chrome, firefox, 웨일 등)라는 클라이언트 프로그램으로 웹 서버 프로그램에 저장된 다양한 데이터를 인터넷 같은 네트워크 통신망을 이용해서 내려받는 서비스를 의미한다. 대표적으로 HTML, CSS, 자바스크립트와 같은 웹 페이지 파일이나 그림, 영상, 음성 파일 등을 내려받을 수 있다.

그렇다면 웹 서비스를 일반적인 파일 내려받기와 같은 것이 아닐까?

웹 서비스는 웹 페이지와 관련된 파일을 내려받는다는 점과 그 파일을 웹 브라우저가 바로 화면에 보여 준다는 점에서 일반적인 파일 내려받기와 차이가 있다.

#### #네트워크의 종류

지금까지 네트워크가 무엇인지 알아보았다.

네트워크는 인터넷처럼 전 세계를 연결할 만큼 규모가 매우 크기도 하고, 자신의 방 컴퓨터와 거실의 공유기를 연결하는 것 처럼 규모가 작기도 하다. 네트워크는 이렇게 규모에 따라 크게 4가지로 구분할 수 있다.

> LAN(local area network): 여러 시스템이 하나의 네트워크 장비(스위치)에 연결된 네트워크  
> WAN(wide area network): LAN이 하나 이상으로 구성된 네트워크  
> CAN(campus area network): 대학 캠퍼스처럼 여러 건물을 연결하는 네트워크  
> MAN(metropolice area network): 한 도시 전체를 연결한 네트워크
{: data-ke-style="style3"}

네트워크는 이 외에도 다양하게 구분할 수 있다. 이름만 조금 다를 뿐 기본 단위인 LAN을 여러 개 연결한 것이다.

#### LAN 톺아보기

이제 가장 먼저 LAN에 대해 살펴보자.

LAN은 집이나 학교, 강의실, 사무실 등 특정 장소에서 가까운 곳에 있는 컴퓨터끼리 연결한 네트워크이다. 아래 사진처럼 컴퓨터와 네트워크 장비(공유기)를 연결하는 선을 흔히 랜선이라고 한다. 즉, 랜선은 글자 그대로 컴퓨터를 LAN에 연결하는 선이다.

보통 랜선의 한쪽은 컴퓨터에, 다른 쪽은 네트워크 장비나 벽의 단자에 연결한다. 이처럼 같은 공간이나 멀지 않은 곳에서 서로 연결된 컴퓨터와 장비는 '하나의 네트워크에 연결됐다' 또는 '같은 LAN 대역이다'라고 표현한다.

#### 광역 통신망 WAN 톺아보기

WAN은 말 그대로 국가, 대륙 등과 같이 멀리 떨어져 있는 넓은 지역을 연결하는 네트워크이다. 여기서 멀리 떨어진 기준은 몇 미터나 떨어졌나가 아닌 가까운 곳을 연결한 LAN과 또 다른 LAN을 하나로 합친 것을 나타낸다. WAN을 구성하는 LAN의 수는 정해져 있지 않다. 그리고 전 세계에서 가장 큰 WAN이 바로 인터넷이다. 그렇다면 인터넷은 무수히 많은 LAN이 하나로 연결된 네트워크인 것이다.

#### #네트워크에서 데이터를 주고받는 방법

내가 컴퓨터에서 다른 컴퓨터로 데이터를 보낼 때는 먼저 대상 컴퓨터를 지정해야 하는데, 이 방식에는 3가지가 있다.

> <strong>유니캐스트(unicast):</strong> 데이터를 특정 컴퓨터 1대에만 보내는 방식. 네트워크 통신에서 가장 일반적  
> <strong>멀티캐스트(multicast):</strong> 데이터를 같은 네트워크에 있는 특정 컴퓨터 여러 대에 보내는 방식. 특수한 경우에만 사용  
> <strong>브로드캐스트(broadcast):</strong> 데이터를 같은 네트워크에 있는 모든 컴퓨터에 보내는 방식. 특정 대상을 지정할 수 없을 때 사용

그렇다면 특정 대상(유니캐스트), 특정 다수(멀티캐스트), 또는 같은 LAN에 있는 모든 대상(브로드캐스트)과 어떻게 통신할 수 있을까?

우리는 특정 장소를 찾을 때 '주소'를 사용한다. 예를 들어 '네이버' 건물을 찾을 때에 '경기 성남시 분당구 정자일로 95'를 이용하듯이 말이다. 네트워크에서도 특정 컴퓨터를 찾아가기 위해 다양한 주소 체계를 이용한다. 대표적으로 MAC 주소, IP 주소, 포트 번호, 도메인 주소, URL 등이 있다.

#### #프로토콜 톺아보기

특정 컴퓨터와 통신하려면 네트워크 주소로 대상을 찾아가야 한다. 그러면 이런 주소는 어디에 작성해야하는 것일까? 우리가 우편이나 택배를 보내거나 받을 때 보내는 사람의 주소, 받는 사람의 주소가 특정한 양식에 맞게 작성되어 있는 것을 확인 할 수 있다. 이처럼 네트워크 또한 데이터를 주고받을 때 다양한 주소를 네트워크 프로토콜이라는 양식에 작성한다.

네트워크 프로토콜 또한 택배 송장처럼 일종의 양식이다. 편지를 보내기 위해서는 편지봉투에, 물건을 보내기 위해서는 박스에 택배 송장을 붙여 이용하듯이, 네트워크에서도 용도에 따라서 알맞은 프로토콜을 사용하여 데이터를 보낸다.

만약 가까운 곳의 컴퓨터와 데이터를 주고받을 때에는 Ethernet(이더넷)이라는 프로토콜을, 멀리 있는 컴퓨터와 데이터를 주고받을 때는 IP를 사용한다. 그리고 특정 컴퓨터에서 실행 중인 프로그램에 데이터를 전달하고 싶으면 TCP나 UDP를 사용한다.
