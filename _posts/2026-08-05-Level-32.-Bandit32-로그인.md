오늘은 Bandit32 문제를 해결해보려고 한다.

이번에도 역시나 Git과 관련된 문제이다. 언제나 그랬듯이 bandit 디렉터리에 git clone 명령어로 다운로드하고 시작하겠다.

다운로드를 하니 역시 repo라는 디렉터리가 있고 안에 README.md라는 파일이 존재한다. 한번 README.md을 읽어보니 이번에는 원격 저장소에 네가 파일을 push 저장하라고 하고 있다. 먼저 파일 이름은 key.txt이고 내용은 'May I come in?'으로 하라고 한다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="364" data-origin-height="38"><span data-url="/assets/images/posts/8b34cb6d864870e102d60fbaac5aef5fb8ff4d9b.png" data-phocus="/assets/images/posts/8b34cb6d864870e102d60fbaac5aef5fb8ff4d9b.png"><img src="/assets/images/posts/8b34cb6d864870e102d60fbaac5aef5fb8ff4d9b.png" loading="lazy" width="364" height="38" data-origin-width="364" data-origin-height="38"></span></figure>

그리하여 vi를 통해 key.txt 파일을 만들어 주고 내용으로는 'May I come in?'을 작성해 주었다. 이제 git에 업로드를 해주면 된다. 하지만 git에는 업로드할 때 3가지 단계가 있다. 이 단계부터 간단하게 한번 알아보자.

만약 자세하게 알고 싶다면 첨부한 링크를 참고해 주면 된다.

> add : Git에 업로드할 목록을 추가한다. → git add \[파일이름\]
{: data-ke-style="style3"}

> commit : 업로드할 목록에서 확정을 한다. +) 설명까지 추가 가능 → git commit -m "메시지"
{: data-ke-style="style3"}

> push : 원격 저장소에 업로드한다. → git push 또는 git push origin \[branch이름\]
{: data-ke-style="style3"}

그럼 한번 명령어를 실행해 보자.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="592" data-origin-height="111"><span data-url="/assets/images/posts/0cd5455c3756a50028b2baa2d384a6a72698bc2a.png" data-phocus="/assets/images/posts/0cd5455c3756a50028b2baa2d384a6a72698bc2a.png"><img src="/assets/images/posts/0cd5455c3756a50028b2baa2d384a6a72698bc2a.png" loading="lazy" width="592" height="111" data-origin-width="592" data-origin-height="111"></span></figure>

먼저 add 명령어를 사용해 보았다. 하지만 다음 경로에 무시해야 할 파일이 있는데 그 파일은 key.txt이고, gitignore를 한번 확인해 보라고 메시지를 보내고 있다. 파일 이름 앞에 "."이 있는 걸 보니 숨긴 파일인 것 같다. 한번 확인해 보자.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="397" data-origin-height="74"><span data-url="/assets/images/posts/933c6506967c1f383338f81f8540259d2e18b06e.png" data-phocus="/assets/images/posts/933c6506967c1f383338f81f8540259d2e18b06e.png"><img src="/assets/images/posts/933c6506967c1f383338f81f8540259d2e18b06e.png" loading="lazy" width="397" height="74" data-origin-width="397" data-origin-height="74"></span></figure>

ls에 -a 옵션을 주어 숨긴 파일까지 모두 살펴보니. gitignore파일이 있는 것을 확인했다. 이 파일을 한번 읽었더니 \*. txt라고 작성되어 있다. 이 뜻은 txt 파일은 올리지 말라는 의미로 이 파일은 txt파일은 무시되도록 되어있는 것이다. 이 이유 때문에 git add key.txt를 입력하면 메시지가 떴던 것이다.

방금 전 git add key.txt 명령어를 입력하였을 때 힌트에도 나와 있듯이 메시지를 무시하고 강제로 실행하려면 -f 옵션을 주면 된다고 말하고 있다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="651" data-origin-height="287"><span data-url="/assets/images/posts/4e73ae82b3e061ac254ac2d401ac56575303232b.png" data-phocus="/assets/images/posts/4e73ae82b3e061ac254ac2d401ac56575303232b.png"><img src="/assets/images/posts/4e73ae82b3e061ac254ac2d401ac56575303232b.png" loading="lazy" width="651" height="287" data-origin-width="651" data-origin-height="287"></span></figure>

그리하여 add를 하고 commit까지 시도를 했더니 나처럼 위와 같이 나오는 사람이 있을 것이다. 

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="617" data-origin-height="38"><span data-url="/assets/images/posts/a87557b30ff5869359e36031f5df20d1d5c7afdb.png" data-phocus="/assets/images/posts/a87557b30ff5869359e36031f5df20d1d5c7afdb.png"><img src="/assets/images/posts/a87557b30ff5869359e36031f5df20d1d5c7afdb.png" loading="lazy" width="617" height="38" data-origin-width="617" data-origin-height="38"></span></figure>

이럴 경우에는 위와 같이 이메일과 이름을 간단하게 작성해 주면 된다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="471" data-origin-height="73"><span data-url="/assets/images/posts/d86bbc826816911c607149e1ca573dc235ab8966.png" data-phocus="/assets/images/posts/d86bbc826816911c607149e1ca573dc235ab8966.png"><img src="/assets/images/posts/d86bbc826816911c607149e1ca573dc235ab8966.png" loading="lazy" width="471" height="73" data-origin-width="471" data-origin-height="73"></span></figure>

이제 다시 commit을 시도하면 될 것이다. 만 add와 commit을 한꺼번에 처리하고 싶다면 commit 뒤에 옵션 -am을 주면 된다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="888" data-origin-height="592"><span data-url="/assets/images/posts/e9cf61ec53776509969710e3d59d256cfd5dc2bc.png" data-phocus="/assets/images/posts/e9cf61ec53776509969710e3d59d256cfd5dc2bc.png"><img src="/assets/images/posts/e9cf61ec53776509969710e3d59d256cfd5dc2bc.png" loading="lazy" width="888" height="592" data-origin-width="888" data-origin-height="592"></span></figure>

이제 push를 해주면 된다. 하지만 이때 master branch로 push를 하라고 했기 때문에 이제부터 로컬 브랜치 master는 origin/master와 연결한다는 의미로 -u 옵션을 넣어서 git push -u origin master라고 입력해 주었다. 입력해 주면 하단에 비밀번호가 나오게 되면서 이번 문제도 끝이 났다.
