전 세계의 파이썬 사용자들이 만들어 놓은 것이 있다. 바로 파이썬 라이브러리이다. '라이브러리(library)'는 '도서관'이라는 뜻 그대로 원하는 정보를 찾아보는 곳이다. 지금부터 라이브러리에 대해 자세하게 알아보자.

sys 모듈은 파이썬 인터프리터가 제공하는 변수와 함수를 직접 제어할 수 있게 해주는 모듈이다.

#### 명령 행에서 인수 전달하기 - sys.argv

> &gt; python test.py abc pey guido
{: data-ke-style="style3"}

명령 프롬프트 창에 test.py 뒤에 또 다른 값을 함께 넣어 주면 sys.argv 리스트에 그 값이 추가된다.

이제 아래와 같이 코드를 작성해보며 확인해보자. argv\_test.py 파일은 C:/doit/Mymod 디렉터리에 저장했다고 가정한다.

> import sys  
> print(sys.argv)
{: data-ke-style="style3"}

명령 프롬프트 창에서 Mymod 디렉터리로 들어간 뒤 아래와 같이 실행해 보자.

> &gt; python argv\_test.py you need python  
> \['argv\_test.py', 'you', 'need', 'python'\]
{: data-ke-style="style3"}

python 명령어 뒤의 모든 것들이 공백을 기준으로 나뉘어서 sys.argv 리스트의 요소가 된다.

#### 강제로 스크립트 종료하기 - sys.exit

> &gt;&gt;&gt; sys.exit()
{: data-ke-style="style3"}

sys.exit는 \[Ctrl+Z\]sk \[Ctrl+D\]를 눌러서 대화형 인터프리터를 종료하는 것과 같은 기능을 한다. 즉 프로그램 파일 안에서 사용하면 프로그램을 중단시킨다.

#### 자신이 만든 모듈 불러와 사용하기 - sys.path

sys.path는 파이썬 모듈들이 저장되어 있는 위치를 나타낸다. 즉 이 위치에 있는 파이썬 모듈은 경로에 사오간없이 어디에서나 불러올 수 있다.

> &gt;&gt;&gt; improt sys  
> &gt;&gt;&gt; sys.path
{: data-ke-style="style3"}

실행하면 경로가 나타날 것이다. (경로에서 ' '는 현재 디렉터리를 말한다.)

> import sys  
> sys.path.append(C:/doit/Mymod")
{: data-ke-style="style3"}

위와 같이 파이썬 프로그램 파일에서 sys.path.append를 사용해 경로 이름을 추가할 수 있다. 이렇게 하고 난 후에는 C:/doit/Mymod 디렉터리에 있는 파이썬 모듈을 불러와서 사용할 수 있다.
