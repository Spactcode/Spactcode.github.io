### <strong>#서로 다른 컴퓨터에서 원격 저장소 함께 사용하기</strong>

이제부터 디렉터리 2개를 만들어 깃허브 실습을 해보겠다. 이때 저장소 2개를 하나는 집에 있는 컴퓨터, 다른 하나는 노트북에 있다고 생각하고 서로 다른 위치에서 같은 계정으로 하나의 원격 저장소에 접근하는 방법을 살펴보겠다.

#### <strong>원격 저장소 복제하기 - git clone</strong>

원격 저장소를 지역 저장소 외에 다른 지역 저장소에서 사용하려면, 원격 저장소에 담긴 내용 전체를 지역 저장소로 가져와야 한다. 원격 저장소를 지역 저장소로 똑같이 가져오는 것을 복제한다고 하거나 클론(clone) 또는 클로닝(cloning)이라고 한다.

이전에 만든 'Doit-study'라는 원격 저장소를 계속 사용하겠다. 이제부터 깃허브에 있는 Doit-study 저장소를 'git\_home'이라는 지역 저장소로 복제하겠다. 저장소 파일 목록 화면에서 Code를 클릭하면 복제할 주소를 확인할 수 있다. 이때 HTTPS 방식을 사용하겠다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="933" data-origin-height="589"><span data-url="/assets/images/posts/28f8e5ea8782e7f7c44b6fd9ac843839ce35ec5d.png" data-phocus="/assets/images/posts/28f8e5ea8782e7f7c44b6fd9ac843839ce35ec5d.png"><img src="/assets/images/posts/28f8e5ea8782e7f7c44b6fd9ac843839ce35ec5d.png" loading="lazy" width="933" height="589" data-origin-width="933" data-origin-height="589"></span></figure>

자신이 원하는 위치에 git\_home 디렉터리를 만들고 VS Code에 작업폴더로 추가한다.

> git clone \[원격 저장소 주소\] .
{: data-ke-style="style3"}

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="534" data-origin-height="353"><span data-url="/assets/images/posts/bc73c2f11cc05e25432beaa8a50b417daa1ce526.png" data-phocus="/assets/images/posts/bc73c2f11cc05e25432beaa8a50b417daa1ce526.png"><img src="/assets/images/posts/bc73c2f11cc05e25432beaa8a50b417daa1ce526.png" loading="lazy" width="534" height="353" data-origin-width="534" data-origin-height="353"></span></figure>

터미널 창에 위와 같이 입력해서 원격 저장소를 현재 폴더로 복제한다. 명령 맨 뒤에 있는 마침표(.)는 현재 디렉터리를 의미한다. 만약 마침표를 추가하지 않으면 폴더 자체가 추가된다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="526" data-origin-height="130"><span data-url="/assets/images/posts/f4bb12d31f69af56328e444e5de6a4ed79675a98.png" data-phocus="/assets/images/posts/f4bb12d31f69af56328e444e5de6a4ed79675a98.png"><img src="/assets/images/posts/f4bb12d31f69af56328e444e5de6a4ed79675a98.png" loading="lazy" width="526" height="130" data-origin-width="526" data-origin-height="130"></span></figure>

이번에는 노트북을 대신할 git\_laptop 디렉터리를 만든다. 이후 VS code 창을 하나 더 열어 작업 폴더로 추가해 주었다. 그럼 현재 작업 폴더가 2개가 만들어져 있는 것을 볼 수 있다. 이후 방금 했던 것처럼 git\_laptop 디렉터리에서 git clone 명령으로 Doit-study 원격 젖아소를 git\_office 디렉터리로 복제한다.

<figure class="imagegridblock"><div class="image-container"><span data-url="/assets/images/posts/9a0ff94610526702bf4e7ac24598680a846c62ad.png" data-phocus="/assets/images/posts/9a0ff94610526702bf4e7ac24598680a846c62ad.png" data-origin-width="632" data-origin-height="348" data-is-animation="false" style="width: 49.4748%; margin-right: 10px;" data-widthpercent="50.06"><img src="/assets/images/posts/9a0ff94610526702bf4e7ac24598680a846c62ad.png" loading="lazy" width="632" height="348"></span><span data-url="/assets/images/posts/a3694e64ed24cacb2c99382975a52085821808d5.png" data-phocus="/assets/images/posts/a3694e64ed24cacb2c99382975a52085821808d5.png" data-origin-width="636" data-origin-height="351" data-is-animation="false" style="width: 49.3624%;" data-widthpercent="49.94"><img src="/assets/images/posts/a3694e64ed24cacb2c99382975a52085821808d5.png" loading="lazy" width="636" height="351"></span></div></figure>

git\_home 디렉터리와 git\_laptop 디렉터리 양쪽에서 git log 명령을 사용해 커밋 로그를 확인해 보자. 양쪽 디렉터리에 똑같이 Doit-study 원격 저장소가 복제된 것을 볼 수 있다. 이렇게 원격 저장소를 복제하면 지역 저장소에 똑같은 커밋 로그가 생기면서 동시에 원격 저장소와 자동으로 연결된다.

#### <strong>집에 있는 컴퓨터에서 작업하고 올리기</strong>

같은 원격 젖아소를 복제한 컴퓨터 2대 가운데 한 곳에서 커밋을 만들고 푸시해 보겠다. 여기에서는 git\_home 디렉터리를 집에 있는 컴퓨터라고 가정하고 작업해 보겠다.

git\_home 디렉터리로 이동한 후 새로운 커밋을 만들어보겠다. f.txt 문서를 열고 간단한 내용을 추가해 주었다. f1.txt 문서에 '9일차&#126;'를 추가한 후 스테이징하고 커밋해 주었다. 커밋 메시지는 'add 9'라고 지정했다. 이후 git push 명령을 사용해 커밋을 원격 저장소에 올려주었다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="685" data-origin-height="282"><span data-url="/assets/images/posts/853e48542273e51e54aaea58800c3861d84635d9.png" data-phocus="/assets/images/posts/853e48542273e51e54aaea58800c3861d84635d9.png"><img src="/assets/images/posts/853e48542273e51e54aaea58800c3861d84635d9.png" loading="lazy" width="685" height="282" data-origin-width="685" data-origin-height="282"></span></figure>

이제 깃허브의 원격 저장소로 접속해서 확인해 보면 파일 목록에서 f1.txt 오른쪽을 보면 방금 커밋한 메시지 add 9가 보일 것이다.

#### <strong>노트북에서 내려받아 작업하기</strong>

집에 있는 컴퓨터에서 커밋을 푸시해서 원격 저장소의 커밋 상황이 달라졌다. 그래서 같은 원격 저장소와 연결되어 있는 회사 컴퓨터에서 작업하려면 먼저 원격 저장소에 새로 올라온 커밋을 가져와야 한다. 여기서 하나의 원격 저장소에 지역 저장소가 2개 이상 연결되어 있을 때, 지역 저장소에서 작업하려면 원격 저장소의 변경 사항을 먼저 가져와야 한다는 점을 이 책에서 강조하고 있다.

> git pull
{: data-ke-style="style3"}

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="497" data-origin-height="219"><span data-url="/assets/images/posts/6058f7f9586c1e58bcf807e8ad5fe1cb948ae8db.png" data-phocus="/assets/images/posts/6058f7f9586c1e58bcf807e8ad5fe1cb948ae8db.png"><img src="/assets/images/posts/6058f7f9586c1e58bcf807e8ad5fe1cb948ae8db.png" loading="lazy" width="497" height="219" data-origin-width="497" data-origin-height="219"></span></figure>

앞에서 원격 저장소를 복제했기 때문에 git\_laptop 저장소는 이미 origin에 연결되어 있다. git\_laptop 디렉터리가 열려 잇는 VS Code에서 git pull 명령을 사용해 원격 저장소에 새로 올라온 커밋을 가져온다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="480" data-origin-height="113"><span data-url="/assets/images/posts/f6540a4180e8a0b109c3153fb613b1e8a00607ce.png" data-phocus="/assets/images/posts/f6540a4180e8a0b109c3153fb613b1e8a00607ce.png"><img src="/assets/images/posts/f6540a4180e8a0b109c3153fb613b1e8a00607ce.png" loading="lazy" width="480" height="113" data-origin-width="480" data-origin-height="113"></span></figure>

이번에는 git\_laptop 디렉터리에서 f1.txt 파일을 수정해 보겠다. VS Code에서 f1.txt를 열면 집에 있는 컴퓨터(git\_home)에서 수정했던 9일 차&#126;가 포함되어 있을 것이다. 노트북(git\_laptop)에서는 '목요일!!'을 추가하고 저장해 주었다.

> git commit -am "add day"  
> git push
{: data-ke-style="style3"}

'add day'라는 메시지와 함께 커밋을 만들고 원격 저장소로 푸시해 준다.

<figure class="imageblock alignCenter" data-ke-mobilestyle="widthOrigin" data-origin-width="686" data-origin-height="272"><span data-url="/assets/images/posts/8668231a08fd234376cbac2e9f62e85abf12dd9b.png" data-phocus="/assets/images/posts/8668231a08fd234376cbac2e9f62e85abf12dd9b.png"><img src="/assets/images/posts/8668231a08fd234376cbac2e9f62e85abf12dd9b.png" loading="lazy" width="686" height="272" data-origin-width="686" data-origin-height="272"></span></figure>

웹 브라우저에서 깃허브로 가서 저장소 파일 목록을 살펴보면 'add day'라는 커밋 메시지가 보인다. 그리고 커밋을 총 5번을 했다는 것까지 확인할 수 있다. 만약 다시 집 컴퓨터(git\_home)에서 작업할 때는 git pull 명령으로 원격 저장소에 잇는 최신 커밋을 가져와 작업을 시작해 주면 된다.
